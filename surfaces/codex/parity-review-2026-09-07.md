## Decision and rejected alternative

Use a thin runtime adapter over the original maintained skills. A second rewritten copy of all four rites would need continuous manual parity maintenance and could omit the same action again. Loading only the matching rite keeps the cost proportional to the requested work; the adapter's overview is routing, not a replacement procedure.

The source remains authored in Bon, exposed through the existing Codex skill link. No change to Claude's original rites or suite release is required for this source-only surface. The record deliberately separates shared behaviour from runtime substitutions and unavailable integrations. No inferred Astra weakness needs compensating text: the observed failure is accounted for by the missing instruction stage and a qualification test that exercised CLI continuation rather than actual close behaviour.
