The /open and /tracker skills were merged into a single /bon skill (skills/bon/SKILL.md). The separation was architectural debt — /tracker couldn't load itself (it depended on a CLAUDE.md instruction or /open's gate step to invoke it), and /open was deleted in 0.9.0 leaving contribution processing orphaned. The merged skill handles both the session-start ritual (contribution processing, hierarchy presentation, direction picking) and the draw-down/draw-up discipline. The manifest.json in this repo still maps skill paths to the old directory names (bon→skills/tracker, open→skills/open) — this is a batterie-de-savoir concern, not bon's plugin.json, but will cause setup.sh drift if not updated.
