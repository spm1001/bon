Skill prose cannot override Claude's procedural prior for CLI flag usage. Four iterations of increasingly forceful guidance in the /open skill — from "prefer JSON stdin" through "no exceptions" through structural reordering to show JSON as the primary pattern — failed to make any of 12 test Claudes pipe JSON to `bon new` instead of using flags. The brief *content* guidance (achievement language, --how field, numbered tactical steps, verifiable --done) landed in every with-skill run. But the mechanical *invocation pattern* (flags vs stdin) is below the skill's reach. The fix was making JSON-from-stdin the CLI default when no title is given and stdin is piped — changing the tool, not the instructions. This has implications for any bon feature where the "right" invocation differs from the CLI convention Claude learned in training.
