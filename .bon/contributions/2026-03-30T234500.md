The auto-handoff LLM path (0.9.0) embeds shell variables into a `nohup bash -c '...'` string via sed single-quote escaping. This is fragile — any single quotes in git commit messages or bon item titles will break the inner script. The mechanical fallback only runs when the LLM path isn't attempted (no transcript or no ccconv), not when it's attempted and fails. A future hardening pass should write a temp script file instead of bash -c, and add a fallback from failed LLM to mechanical output.
