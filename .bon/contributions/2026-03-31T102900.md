Claude Code resolves plugin skills by directory name, not the SKILL.md frontmatter `name:` field. Renaming the `name:` without renaming the directory means the old invocation path stays active and the new one never registers. Similarly, hook scripts in `hooks/` are inert unless registered in `.claude-plugin/plugin.json` under the `"hooks"` key — the runtime doesn't scan directories. Both of these are silent failures: no error, just nothing happens. A version bump is required after fixing either, because `claude plugin update` compares versions, not content — same version means "already up to date" even if files changed.
