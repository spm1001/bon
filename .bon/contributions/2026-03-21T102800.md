The Dolt backend was added without introducing any abstraction — no base classes, no strategy pattern, no backend registry. Six `if _get_backend() == "dolt"` branches at function boundaries in storage.py, each lazily importing from dolt.py. This is deliberately simple and deliberately removable. If Dolt doesn't earn its keep, deleting the backend is a one-file removal plus six branch deletions. The truncate-and-reinsert write strategy (DELETE all prefix rows, INSERT all, DOLT_COMMIT) was chosen to mirror JSONL's "rewrite the whole file" semantics exactly — this keeps the two backends' concurrency guarantees identical, at the cost of per-item efficiency that doesn't matter at bon's scale.
