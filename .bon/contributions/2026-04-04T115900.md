The publish pipeline for plugin changes is: edit source in repo → commit → push to GitHub → `claude plugin marketplace update` → `claude plugin update` → CLI reinstall via `uv cache clean + uv tool install --force --reinstall` → full session restart (`/exit` then `claude`). Reloading plugins mid-session doesn't trigger SessionStart hooks and doesn't refresh skill SKILL.md content already loaded into context. The marketplace index fetches from the GitHub repo at update time, not from a separate registry — so pushing to GitHub IS publishing, but the version in plugin.json must change or the update command reports "already up to date" even when file contents differ.
