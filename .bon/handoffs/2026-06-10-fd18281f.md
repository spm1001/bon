## For Claudes to come

**Bon resolves like git now, and the board can't silently lie in three old ways.** `_data_dir()` walks up from CWD to find `.bon` (stopping at a `.git` boundary; above CWD only a prefix-bearing board counts, so `~/.bon` is never adopted); session identity for tactical claims is the .bon root, not the bare CWD. A cloned repo missing its gitignored markers fails loudly with a reconnect recipe (`bon init` completes a marker-less `.bon` non-destructively) instead of presenting a phantom empty board. Done outcomes with open children stay visible in every list view. Dolt writes are atomic: explicit rollback in all three write paths, `waiting_for` is TEXT (the varchar(500) cliff that caused the 06-07 half-wipe is gone), and oversized values fail pre-flight with a named item and field.

**The publish pipeline changed underneath this repo on 2026-06-10.** spm1001/batterie (no -de-savoir) is the single marketplace; it *vendors* plugins inside itself, so pushing this repo is no longer publishing. The recipe: push source → `gh workflow run "Assemble plugins" -R spm1001/batterie` (drift-guarded bot vendors all source repos from their GitHub HEADs) → `claude plugin marketplace update batterie` → `claude plugin update bon@batterie` → reinstall the CLI. Version coherence has exactly two points: source `.claude-plugin/plugin.json` and the bot-vendored copy; the marketplace entry pins nothing.

**CWD-keyed tactical claims conscript parallel sessions — including agents your own tests spawn.** The civelu forensics: a tester burst-verifying réceptionnaire's email dispatch had one of its own test emails spawn a fresh CC session into the repo cwd; the UserPromptSubmit hook injected the live tactical and the dispatched Claude competently advanced another session's steps and closed an item under them, with an accurate note. Every mutation was a real CLI call — the Dolt commit log (`dolt_log` + `dolt_diff_items`, messages carry the argv) attributes everything, and session transcripts close the loop. Generalised: any same-CWD parallel session (bg fork, second roster session, dispatched agent, test probe) holds the same claim and is invited to advance it. Documented in the open skill; structural fix is bon-hibehi.

**A field report's remedy can be stale while its problem is real.** Twice tonight the briefed fix was unimplementable (narato's "anchor to line-start" — newlines are collapsed before the regex; cepumi's "sort by date-prefixed filename" — handoffs are session-id-named) but the underlying defect was exactly as described. Verify the brief's premise against the actual artefacts before implementing its remedy; the problem statement ages better than the prescription.
