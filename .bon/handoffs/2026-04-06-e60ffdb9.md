## For Claudes to come

When changing a storage format, the code change is the easy part — the blast radius is in the scripts, hooks, and consumers that read the old format directly. We touched four scripts across three repos that would have silently produced empty results after migration. The fix pattern is uniform: check `.bon/backend`, dispatch to CLI for Dolt, keep direct file reads for JSONL. But discovery requires knowing every consumer exists — and they're scattered across repos. The lesson: before any storage migration, grep for the old filename across ALL repos, not just the ones you think consume it. `audit_survey.py` had already been fixed by a previous Claude; the three that hadn't were silent failures waiting to happen.

The broader principle: infrastructure transitions have two phases. Phase 1 is making the new thing work (Dolt backend, migrate command). Phase 2 is making everything else aware the old thing is gone (hooks, scripts, adapters, instruction shards). Phase 2 is where reliability lives.
